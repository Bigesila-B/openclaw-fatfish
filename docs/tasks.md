# 图片和视频生成任务

生图、生视频指令和自然语言工具先保存任务并立即回复编号，后台完成后发回原会话。默认并行 2 个、最多 20 个未结束任务；重启后记录保留，避免长视频占住一次聊天调用。

```text
/fish tasks
/fish task 任务编号
/fish task resume 任务编号
/fish task cancel 任务编号
/fish task send 任务编号
```

只能在原通道、原机器人账号、原用户、原会话及线程查看和操作自己的任务。状态回复不包含提示词或文件路径。生成、恢复查询和发送前重新检查权限、黑名单和供应商开关。

Agnes 视频返回服务端任务编号后立即保存。查询超时进入“等待恢复查询”，`resume` 只查询原编号，不提交新生成请求；默认 Gateway 重启会恢复此类任务。`tasks.resumeOnStart:false` 可禁止自动恢复等待任务。

创建请求发出后网络断开、未获得服务端编号时，状态是“提交结果不确定”。插件不盲目重试 POST，先核对服务商记录。服务端明确拒绝繁忙请求时会失败，用户可稍后重新发起，不会持续高频自动重提。

生成结果先保存再发送。取得通道回执后完成；发送途中重启或网络异常会标记待确认，先检查 QQ，再执行 `send`。重发复用已有结果，取得回执的文件不重复发送。媒体层的 `/fish resend 编号 [file]` 也可使用；媒体编号与生成任务编号不同。

`cancel` 只停止本地查询及自动发送，不保证撤销服务端任务或退款。持有服务端编号的已取消任务可由原用户显式恢复查询。ComfyUI 暂不支持跨重启恢复服务端查询；提交途中重启会保留不确定状态，不自动重复生成。

在 `plugins.entries.fatfish.config.tasks` 可设置 `maxConcurrent`（1–8）、`maxPending`（1–100）、`resumeOnStart`（默认 true）、`notifyFailures`（默认 true）。通知不含服务商原始响应或密钥。提示词和结果引用保存在 Gateway 状态目录 `fatfish/tasks.json`，按私人数据保护。文件状态仅支持一个 Gateway 进程，不是分布式队列；终态历史有数量上限，缓存过期或远程地址失效后不保证重发。
