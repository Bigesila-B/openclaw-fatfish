# 可选群聊策略

这是参考自然群聊行为独立实现的轻量策略，并非移植 MaiBot 完整调度器或长期记忆。默认关闭，明确指定的群才生效，不改变私聊。策略在同一 OpenClaw 消息链路内做去重、短期观察、突发消息合并与限频，不运行第二个自动回复机器人。

合并到插件 `config`：

```json
{
  "chat": {
    "enabled": true,
    "allowGroups": ["123456789"],
    "mode": "natural",
    "cooldownSeconds": 45,
    "replyProbability": 0.15,
    "mergeWindowMs": 500,
    "maxContextMessages": 8
  }
}
```

`mention` 模式抑制未 @ 的普通闲聊；`natural` 允许概率回复并按群限频。@、明确问题/请求及斜杠指令不被闲聊概率拦截；功能权限、黑名单仍生效。突发时较早的普通闲聊会被合并，最新消息通过后附带短期观察材料。

仅在内存中保存最近两分钟的有限文本，最多 100 个群，重启清空；黑名单用户不进入后续提示。材料作为引用数据给模型，不覆盖系统指令。说话风格另见[人格配置](persona.md)。附加观察材料需 `hooks.allowConversationAccess:true`，并且宿主未显式禁止提示修改，字段差异见人格教程。

策略只能处理宿主已交给插件的消息。通道过滤未 @ 消息时插件无法看到它们，需要真实群验证。旧宿主缺少明确 @ 标记时保留原有路由，避免吞掉已放行的 @ 消息，此时不保证闲聊限频。群、账号及会话彼此隔离。
